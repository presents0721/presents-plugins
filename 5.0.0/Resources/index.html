自定义用例

在任意插件目录建 Tests/*.test.cjs，框架会自动发现并在 Node + DOM 桩里执行。可用全局：test(name, fn)、assert(cond, msg)、assertEqual(a,b)、assertThrows(fn)、document、window。
test('挂件不会留下遮挡层', () => {
  const box = document.createElement('div');
  box.id = 'my-widget';
  document.body.appendChild(box);
  assert(document.getElementById('my-widget'), '挂件应被创建');
  box.remove();
  assert(!document.getElementById('my-widget'), '清理后不应残留');
});
